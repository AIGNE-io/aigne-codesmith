# 与机器人互动

AIGNE CodeSmith 旨在成为您拉取请求工作流中的一个交互式助手。您可以直接与该机器人交流，以提出后续问题或指示它跳过对某些拉取请求的审查。本指南概述了这些互动的流程。

## 回复审查评论

在机器人发布审查后，您可能会有疑问或需要对其建议进行澄清。您可以通过在拉取请求中直接回复其审查评论来与机器人进行对话。

当您回复由机器人发起的评论串时，它会自动将您的消息作为后续问题处理。机器人将利用原始评论的上下文、周围的代码以及您的问题来提供相关的回复。

如果您希望将机器人引入一个非由它发起的评论串，您必须通过其用户名 @codesmith 来提及它。

### 工作原理

1.  **机器人发布审查：** 机器人在您的拉取请求中的特定代码行或代码块上留下评论。
2.  **用户回复：** 您对机器人的评论发布一条回复。
3.  **机器人响应：** 机器人处理您的回复，并在同一评论串中发布自己的响应，从而继续对话。

这样就可以围绕特定的代码更改进行有针对性的、基于上下文的对话。

```text
用户：@codesmith 你能解释一下为什么这种方法更好吗？
```

## 跳过审查

在某些情况下，拉取请求可能不需要 AI 审查，例如次要的文档更新或微不足道的修复。您可以通过在拉取请求的描述中包含一个关键词，来指示机器人跳过对该拉取请求的审查。

要跳过审查，请将以下文本添加到您的拉取请求描述正文的任意一行：

```text
@codesmith: ignore
```

当机器人被触发时，它会检查拉取请求描述中是否包含此关键词。如果存在该关键词，操作将平稳终止，不会执行审查或发布任何评论。这必须在操作运行之前完成。

### 使用示例

以下是一个包含了忽略关键词的拉取请求描述示例。

```markdown
此 PR 修复了 README 文件中的一个小拼写错误。不涉及代码更改。

@codesmith: ignore
```

## 总结

与 CodeSmith 机器人互动非常简单直接。要提出后续问题，请回复机器人的审查评论。要将某个拉取请求从 AI 审查中排除，请在其描述中添加 `@codesmith: ignore` 关键词。这些功能让您对审查过程有更大的控制权。

有关配置机器人审查哪些文件的更多信息，请参阅[配置文件范围](./guides-configuring-file-scope.md)指南。
